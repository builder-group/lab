# Words

Use these with the person. One word per thing.

| Say | Not | Meaning |
| --- | --- | --- |
| Project | session, file | The document |
| Scene | World, Settings | The whole film, selectable: the first row of Layers |
| Song | source, audio, music | The MIDI file or recording; a film has one |
| Note | MIDI event | One musical event, by name: C4 |
| Beat | onset, transient | An event found in a recording |
| Marble | ball, lane | The ball |
| Hit | contact, collision | The moment a marble strikes its note |
| Dot | ghost, marker | Where a marble is at a hit's time |
| Part | track, voice | One marble's slice of the song, or Backing |
| Backing | dropped, unassigned | Notes no marble plays; heard in the film |
| Track Piece | object, prop, asset | One of any kind of thing the marbles run on, when the kind doesn't matter; after the first mention, piece |
| Platform | bar, pad, peg | The piece that plays a note |
| Rail, Tunnel, Windmill, Bowl | scenery | The other pieces. A Rail's Layout is Drawn, Curve, C, Chain or Switchback |
| On Time, Early, Late, Missed, Stopped, Blocked, Open | | A hit's status |
| Compose, Film | Design | The two workspaces |
| Theme | style, preset | Dresses the whole film; one per project |
| Gravity | Marble Speed | How fast all marbles fall; the command stays `marble.speed` |
| Format | Frame, aspect | The shape of the film |
| Tilt | Pitch | The camera's angle; the field stays `pitch` |
| Skin | material, asset | How one piece looks |
| Decor | prop | Things on the wall; no hitbox |
| Pack | bundle, plugin | A file of themes, skins and decor. Add Pack…, Export Pack… |
| Layer | object | A row in Layers |
| Shot | keyframe | A camera move at a time |
| Sway | wobble, drift | How much the camera turns and rolls on its own |
| References | moodboard | Images and words for the look |

Write plainly: say what happened and what to do next. Name things in Title Case as the app shows them.
